# 🎹 JADE 88 Keys Studio

An elegant 88-key virtual piano built entirely with HTML, CSS, and JavaScript.

## ✨ Features

- Full 88-key piano range (A0 → C8)
- Beautiful modern jade-themed interface
- Multiple instruments & soundfonts (might not work) 
- MIDI playback support
- Recording & playback
- Reverb and echo effects
- Visualizer modes
- Sustain pedal
- Scale highlighting
- Metronome
- Keyboard controls
- Pure client-side project
- No installation needed
- Lightweight use

---

# 🎼 Keyboard Controls

| Key | Action |
|------|------|
| A → K | Play notes |
| Z / X | Change octave |
| SPACE | Sustain pedal |
